## Первые шаги после создания репозитория

1. Установите Git LFS: `git lfs install` (один раз на машине). Файл `.gitattributes` уже настроен.
2. В Unity Hub создайте проект **внутри** этого репозитория в папке `UnityProject/` (Unity 2022.3 LTS, шаблон 3D/2D/VR).
3. Скопируйте `starter/Assets/*` в `UnityProject/Assets/` — там заготовки папок, скрипт-пример и EditMode-тест.
4. Первый коммит: `git add . && git commit -m "init from template"` — проверьте, что `Library/` не попал в git.

## Структура репозитория

```
UnityProject/          Unity-проект (Assets, Packages, ProjectSettings)
  Assets/_Project/     ВЕСЬ ваш код и ассеты здесь (Scripts, Scenes, Prefabs, AI, Tests)
starter/               заготовки для копирования в UnityProject/Assets
docs/report/           разделы пояснительной записки (00–05)
docs/adr/              архитектурные решения
docs/defense/          презентация
results/               метрики экспериментов (csv/json), графики
scripts/analysis/      Python-скрипты для обработки результатов (опционально)
```

## Правила репозитория

- Ветки: `main` (стабильная), `feature/<что>` — через Pull Request.
- Сцены и префабы конфликтуют плохо: один человек — одна сцена в один момент; используйте префабы.
- Крупные ассеты (текстуры, модели, звук) — только через LFS; лимит бесплатного LFS на GitHub — 1 ГБ, не кладите магазинные пакеты целиком.
- Метрики (FPS, время принятия решения, % успешных сценариев) экспортируйте в `results/` — они нужны в разделе 4 записки.
